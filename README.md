# Demo AWS Amplify Hosting

Web statis sederhana untuk tugas UTS: tutorial deploy web application dengan AWS Amplify.

## Cara pakai
1. Ganti placeholder `[NAMA]`, `[NIM]`, `[NAMA MATA KULIAH]` di `index.html`.
2. Upload ke repository GitHub (branch `main`).
3. Di AWS Amplify: Create new app, pilih GitHub, pilih repo dan branch, lalu Save and deploy.
4. Untuk demo CI/CD: ubah teks versi `1.0` menjadi `2.0` di `index.html`, lalu `git add . && git commit -m "update versi 2.0" && git push`.

Tidak perlu build command karena ini web statis.
